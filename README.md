🤖 JARVIS – Frontend AI HUD

A futuristic JARVIS-inspired AI assistant interface built using HTML, CSS, and Vanilla JavaScript.
This project simulates a voice-controlled AI HUD similar to Iron Man’s JARVIS, focusing on UI, animations, and browser speech APIs.

⚠️ This is a frontend-only project created for learning, practice, and UI experimentation.

✨ Features

🎙️ Voice Recognition (Speech-to-Text)

🔊 Voice Response (Text-to-Speech)

🧠 Simple AI-style command handling

🟢 Dynamic system modes (ONLINE / ANALYSIS / COMBAT)

💫 Animated circular HUD interface

🧾 Live command console output

🎨 Color-changing UI based on modes

🚀 Lightweight & framework-free

🛠️ Tech Stack

HTML5 – Structure

CSS3 – Animations, HUD design

JavaScript (Vanilla) – Logic & speech handling

Web Speech API – Voice recognition & synthesis

▶️ How to Run

Clone the repository

git clone https://github.com/kamill-dev/Jarvis-frontend.git


Open the project

cd Jarvis-frontend


Run

Simply open index.html in your browser

Use Chrome / Edge for best voice support

Click START JARVIS

Allow microphone access

Speak commands like:

hello

who are you

status

combat mode

analysis mode

🗣️ Supported Voice Commands
Command	Action
hello / hi	Greeting response
who are you	AI identity
status	System status
combat	Activates combat mode
analysis	Switches to analysis mode
